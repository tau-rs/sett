# sett

The design system of arch: tokens, Lit `sett-*` elements, Storybook. `DESIGN.md` wins on look; the ADRs win on behaviour and vocabulary.

The record of decisions lives in [`tau-rs/arch-design`](https://github.com/tau-rs/arch-design): the spec, the flow pages and the ADRs. sett implements them and does not decide alone; what it refuses or cannot express is filed there as an issue labelled [`from:sett`](https://github.com/tau-rs/arch-design/issues?q=label%3Afrom%3Asett).

**Synced to: ADR 0029** (2026-10-03).

Agents start at `AGENTS.md`; `HANDOFF.md` lists the states every component must have a story for.
