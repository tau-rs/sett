# Map primitives

Map primitives are values, not components: arch's WebGL layer reads the `sett-tokens` crate, the same numbers as this page. Items are 18 px boxes with a 10 px mono label that never scales; ports have round ends; externals are dashed. Overlays stack by one rule: outline = session, fill = plan or finding.

export const Swatch = ({ name, l, d }) => (
  <tr>
    <td style={{ fontFamily: 'var(--sett-font-mono)', fontSize: 'var(--sett-font-size-sm)' }}>{name}</td>
    <td><span style={{ display: 'inline-block', width: 40, height: 18, borderRadius: 3, background: l, border: '1px solid var(--sett-color-line)' }} /> <code>{l}</code></td>
    <td><span style={{ display: 'inline-block', width: 40, height: 18, borderRadius: 3, background: d, border: '1px solid var(--sett-color-line)' }} /> <code>{d}</code></td>
  </tr>
);

## Session overlays

Outline in the session's main colour, fill in its tint; sub-agents outline in the sub shade. Assign in this order: {sessionOrder.join(' · ')}.
