# Tokens

Every token, straight from `packages/tokens/dist/tokens.json` (built from the DTCG source in `packages/tokens/src`). The name is the CSS custom property: `--sett-<path>`. Components reference these and never a raw value.

export const mono = { fontFamily: 'var(--sett-font-mono)', fontSize: 'var(--sett-font-size-sm)', whiteSpace: 'nowrap' };
export const Swatch = ({ value }) => (
  <span style={{ display: 'inline-block', width: 40, height: 18, borderRadius: 3, verticalAlign: 'middle', marginRight: 6, background: value, border: '1px solid var(--sett-color-line)' }} />
);
export const Value = ({ t }) => (
  <>{t.type === 'color' ? <Swatch value={t.css} /> : null}<code>{t.css}</code></>
);
export const themed = tokens.light.map((l, i) => ({ light: l, dark: tokens.dark[i] }));

Colours, session colours, map primitives, syntax and editor colours. The dark set carries the same names.
